# 媒体配置界面规范：参考 DutyDeck

状态：v0.2.0 配置、资源、记录与任务队列界面的设计基准。用户指定以 DutyDeck 媒体配置为样式参考；首版实现与验收范围见 README。
本规范替代此前“图片／视频／声音三分类、列表与长表单同屏”的独立插件规划。

## 已核对的来源

源码根：`DutyDeck/apps/electron/src/renderer/components/settings/`。

- `MediaSettings.tsx`：一级分区与稳定导航值。
- `MediaSettingsPage.tsx`：列表页与独立编辑页的统一页面结构。
- `ImageGenerationSettings.tsx`：供应商配置列表、搜索、动态表单、启用模型及目录获取。
- `primitives/SettingsUIConstants.ts`：标题、标签、说明、设置行、卡片和分隔线样式。
- `primitives/SettingsCard.tsx`、`SettingsRow.tsx`、`SettingsSection.tsx`：分组和操作布局。

本次核对的是源代码结构与样式类，没有声称已经在运行中的 DutyDeck 窗口做像素级对比。
移植视觉和交互约定，不依赖原项目 Electron IPC、Jotai store 或私有配置。

## 1. 一级导航

沿用原媒体配置的分组顺序与使用习惯：

| 页面 | 内容 |
|---|---|
| 生成模型 | 即梦、OpenAI 图片兼容、MiniMax 等图片／视频供应商配置 |
| 音频生成 | 小米 MiMo、MiniMax 等语音模型、音色和格式 |
| LibTV | 独立 MCP/OAuth 服务入口及真实连接状态 |
| 服务链接 | ComfyUI 等自托管服务地址、认证与明确触发的连接检查 |
| 本地工作流 | API 工作流列表、导入、输入绑定、输出定义与版本 |

默认进入“生成模型”。图片／视频筛选属于生成模型页面内部，不替代一级导航。
v0.2 增加顶层“配置／记录／任务队列”。记录与队列只读查看本插件空状态和用户选择
的 ComfyUI 服务器数据，可能包含其他客户端任务；不提供取消、重试或提交按钮。
独立插件后续的“任务／结果”是顶层功能入口，不塞进供应商编辑表单。
尚未实现的页面呈现明确空态和能力限制，不显示虚假的成功状态。

## 2. 列表页与编辑页分离

**列表页：** 标题与右侧“添加”按钮；紧凑导航和搜索；统一分组列表。
每行左侧为名称、供应商及简短模型摘要，右侧为启用状态和编辑／更多操作。
不要默认展开每个账号的地址、密钥、模型参数和工作流 JSON。

**添加／编辑页：** 左上返回箭头与明确标题；独立表单主体；底部右对齐“取消／保存”。
编辑时不保留另一列完整供应商目录，不把列表搜索和新增按钮混入表单。
返回与取消采用相同的未保存修改保护；保存期间禁止重复提交和离开。

## 3. 表单层级

生成模型编辑页按 DutyDeck 的结构组织：

1. **基本信息**：供应商类型、配置名称、对应连接／登录字段、启用开关。
2. **已启用模型**：逐项列出模型，支持图片／视频筛选、移除和添加自定义模型。
3. **可用模型**：右侧“从供应商获取”，显示真实查询结果和添加操作。
4. **错误与操作**：就近展示可操作错误，底部取消／保存。

供应商字段随类型变化：即梦显示 CLI 与账号接入区；HTTP 服务显示地址和密钥；
MiniMax 的专属字段只在适用时出现。音频配置使用相同视觉结构，再加入模型与音色选择。

不以 `image:model-id` 多行原始文本作为常规模型管理入口。高级参数按模型展开。
ComfyUI 连接与工作流分开维护，工作流 JSON 编辑留在工作流页面，不污染普通账号配置。

## 4. 视觉基准

采用 DutyDeck 设置组件的密度和层级，映射到插件的主题变量：

- 页面编辑标题：参考 `text-lg font-medium`；返回按钮约32px。
- 区块标题：参考 `text-base font-semibold`；标签 `text-sm font-medium`。
- 说明文字：参考 `text-sm text-muted-foreground`，简短描述放在相关字段附近。
- 设置行：参考 `px-4 py-3`，左侧名称与说明，右侧控件或操作。
- 分组卡片：参考 `rounded-xl settings-card`；弱行分隔，参考 `border/25`。
- 组内间距参考 `space-y-3`，编辑页区块间距参考 `space-y-6`。
- 颜色跟随宿主明暗主题，不另外引入品牌渐变、大图背景或额外装饰。
- 使用自定义可访问选择控件、开关、图标按钮；不使用突兀的原生系统下拉。
- 不照搬每个组件的边框：保持单层分组，避免卡片内再套多层完整边框。
- 窄屏时设置行上下排列、按钮可换行；导航可横向滚动，不能把页面整体撑宽。

上述字号为默认 Tailwind 尺度参考，最终以实际渲染和宿主缩放测试为准，不宣称像素复刻。

## 5. 继承交互，不复制不合适的行为

- API Key 默认遮挡，显式切换可见；不沿用原图像表单默认明文显示的行为。
- 获取模型、检查连接和登录均由用户明确触发，不因进入页面而自动访问远端。
- 没有 CLI 执行能力时显示接入说明，不渲染可成功执行的假登录按钮。
- 密钥是否持久化以实际安全存储能力为准，不能因参考 DutyDeck safeStorage
  的页面就宣称新宿主也支持加密存储。
- “已保存”“已启用”“目录可访问”“生成可执行”独立表达，不用一个绿点混为一谈。
- 供应商切换、复制配置、并发编辑、迟到目录响应和工作流文件导入均保留已有防护。
- 删除使用二次确认，置于行尾更多操作或详情次要位置，不与主保存操作抢视觉优先级。

## 6. 实现验收

先在无账号、无真实网络的隔离页面完成列表→添加→保存→编辑→返回完整路径。
验证未保存保护、模型增删、类型筛选、目录加载／失败、默认项、键盘焦点及敏感字段遮挡。

在1440／900／600／390px和明暗主题下检查列表、普通表单与长工作流：没有横向溢出，
主要操作可达，说明文字不形成大段首屏噪声。视觉验收应选取 DutyDeck 对应页面截图对照；
首版已完成隔离浏览器交互与响应式检查；未与运行中的 DutyDeck 窗口做像素级截图比对。

本规范仅决定新插件的配置界面，不恢复影视工厂内已移除的媒体配置页。
